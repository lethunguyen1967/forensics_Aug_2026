# Computer and Disk ForensicsAutopsy: 

## Disk and File Analysis

### Autopsy: 
A graphical user interface for The Sleuth Kit, used for timeline analysis, keyword searches, and data carving. 

### Sleuth Kit: 

A command-line collection of low-level tools for analyzing file systems and recovering deleted files.

### Bulk Extractor: 

A fast tool that scans disk images in parallel to extract useful artifacts like email addresses, credit cards, and URLs.

## Memory and Live System Forensics

### Volatility: 

A powerful Python-based framework to extract digital artifacts and analyze volatile memory (RAM) dumps.

### RegRipper: 

An open-source tool used to extract and parse useful data from Windows registry hives.

### Velociraptor: 

A tool for endpoint visibility, digital forensic investigation, and targeted artifact collection.

### Complete Forensic Distributions (OS)CAINE: 

An Ubuntu-based live Linux distribution that bundles a massive collection of open-source forensic tools into a desktop environment.

### SIFT Workstation: 
A platform created by the SANS Institute equipped with advanced incident response and forensic tools
